# RedNote Lite（小红书 macOS 轻量桌面客户端）

一款基于 **macOS 原生 SwiftUI + WebKit (`WKWebView`) + SQLite** 开发的极简、低内存小红书桌面客户端，无 Electron / Chromium 膨胀，支持浏览、评论、本地+官方收藏、自动浏览历史、互动通知与创作者私信，并内置一键释放内存与休眠模式。

## 核心特性

- **极低内存占用**
  - **单 WebView 架构**：全局仅维持 1 个 `WKWebView`，外链自动交由系统浏览器打开，避免多标签渲染进程内存雪崩。
  - **省内存渲染模式（Eco Mode）**：为瀑布流卡片注入 `content-visibility: auto`，通过 `IntersectionObserver` 自动暂停离屏视频，禁止后台视频预加载与自动播放。
  - **实时内存监控与一键释放**：顶部工具栏实时显示主进程物理内存（`phys_footprint`），支持「轻量释放缓存（保登录态）」、「深度重置渲染进程」与「休眠模式（彻底销毁 WebView，常驻 ~25–35 MB）」。
  - **自动后台休眠**：应用切到后台达到设定时长后自动释放网页内存，再次打开一键恢复上次浏览位置。
- **完整浏览与快速评论**
  - 原生 macOS 工具栏快速切换 **发现 / 互动通知 / 创作者私信 / 个人主页**，内置搜索框（`⌘K`）。
  - 支持原生评论浏览与发表，按 `⌘J` 一键滚动并聚焦到当前笔记评论输入框。
  - 可选「清爽模式」隐藏非必要下载 App 浮窗。
- **双层收藏体系**
  - **账号官方收藏**：直接在小红书页面点击收藏，实时同步至小红书账号。
  - **本地轻量收藏夹（SQLite）**：按 `⌘D` 一键收藏当前笔记（自动提取标题、作者、封面缩略图与链接），支持**自定义分类文件夹、个人备注、本地瞬时搜索与导出 Markdown**。
- **自动本地浏览历史**
  - 浏览任意笔记、搜索页或博主主页自动记录到本地 SQLite（按 **今天 / 昨天 / 本周 / 更早** 分组，自动去重并统计访问次数），支持关键词搜索、一键转入本地收藏夹与自动容量上限清理。
- **互动通知与私信**
  - **互动通知**：直达 `xiaohongshu.com/notification` 查看评论、点赞、收藏、@ 提醒。
  - **创作者私信**：直达 `creator.xiaohongshu.com/creator/chat`（与主站共享同一登录态 Cookie）。

## 构建与运行

需要 macOS 14+ 与 Xcode Command Line Tools（Swift 6+）。

```bash
# 运行核心单元测试
swift test

# 编译并打包成原生 macOS .app 应用
chmod +x scripts/build_app.sh
./scripts/build_app.sh

# 启动应用
open dist/RedNoteLite.app
```

也可以将 `dist/RedNoteLite.app` 直接拖入 `/Applications`（应用程序）目录作为常驻桌面 App 使用。

| `⌘K` | 聚焦顶部搜索框 |
| `⌘J` | 快速定位到笔记评论输入框 |
| `⌘D` | 收藏 / 取消本地收藏当前笔记 |

| `⌘Y` | 打开 / 关闭浏览历史侧边栏 |
| `⌘M` | 打开 / 关闭内存监控与优化面板 |
| `⌘⇧K` | 一键轻量释放缓存内存（保留登录态） |
| `⌘⇧H` | 立即休眠 / 唤醒网页视图 |
| `⌘[` / `⌘]` / `⌘R` | 后退 / 前进 / 刷新 |
